# STM32 MPPT Solar Charge Controller (capstone)

Synchronous-buck MPPT charger for a 12 W panel and a 12 V 2.2 Ah SLA battery, on an STM32 Nucleo-F401RE, bare-metal C.

**Status (2026-11-11):** architecture, component selection, LTspice v1.5 (100 kHz), P&O + charge-FSM firmware logic (compiled, not flashed) and a software-in-the-loop simulation are done. No hardware built, no bench data. See `docs/simulation_results.md`.
Full details, decisions and open issues: **[PROJECT_STATE.md](PROJECT_STATE.md)**, which is the single source of truth.

## Conventions

- **Simulation versions:** copy to a new number (`1.5`, `1.6` …) before changing a schematic; never edit an old version. Record each one in `SIM_FILE_HISTORY.md`.
- **Bench data:** `bench/YYYY-MM-DD_<what>.<ext>`, e.g. `2026-10-20_pwm_deadtime_CH1_CH1N.png`, `2026-10-20_uart_po_run1.txt`. Add one line of context in `bench/NOTES.md`.
- **Decisions:** when something moves from PROPOSED to DECIDED, update `PROJECT_STATE.md` the same day.
- **Large files:** LTspice `.raw` (≈100 MB each) and `.db` files are regenerated by re-running; don't back them up or commit them.
